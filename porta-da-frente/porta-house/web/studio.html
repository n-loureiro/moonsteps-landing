Set up automatic generation

Generation sends the collected property photos and plans to OpenAI and uses your API account. The key stays in the local app process. Collection and imported scenes work without a key.

export OPENAI_API_KEY="your-key"
npm start

Close this app’s server first, then restart with the key set. You can choose a compatible vision model through OPENAI_MODEL.

A model you can inspect

The geometry comes from one shared renderer. Each property gets its own source bundle and scene description, so you can correct a wall, add a missing plan, or regenerate the HTML without starting over.

The result is an architectural approximation. Floor plans establish room relationships; photographs suggest roof shapes, heights, materials and landscaping. Where the listing leaves a gap, the model must say so.

Video and virtual-tour links are recorded. Their contents are only used when you supply extracted frames or a local video through the command-line tool. Missing or uninspected material remains visible in the source record.
