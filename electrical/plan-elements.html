As alterações ficam neste navegador. Guarde também o ficheiro de projeto para fazer cópias ou continuar noutro dispositivo. Exportação para revisão, não é um projeto validado: confirmar com o técnico responsável. Os circuitos e restantes peças não são recalculados.
